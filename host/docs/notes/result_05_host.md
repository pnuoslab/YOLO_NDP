|---|---|---|---|---|---|
| 기본 | 259 | **≈ 510%** | 93% | **0** | 'darknet' 이름 스레드 약 127개가 각 2~3% |
| cv1 | 132 | **≈ 242%** | 91% | 0 | 주로 디코더(`av:h264:*`) 2~3% |

- **확정**: 기본 설정에서는 OpenCV(TBB) 작업자 약 127개가 프레임 루프 동안 짧게 자주 깨어나, 합계 약 270% CPU를 쓴다. cv1에서는 그 스레드들이 없다.
- **지지되지 않음**: "한 작업자가 메인 스레드와 같은 물리 코어(SMT 형제)에서 계속 돈다"는 후보. 두 표본 모두 메인 스레드의 형제 CPU(cpuN ↔ cpuN+64)에 바쁜 스레드가 없었다.
- **판정 불가 (관측만)**: 짧고 잦은 깨어남이 `mat_to_image`(1080p)와 `letterbox_image`(1440p·4K)를 어떻게 느리게 하는지. 후보로 메모리 대역폭·캐시 경쟁, 스케줄러가 메인 스레드를 다른 코어로 옮기는 것(표본에서 메인 스레드는 CPU 93 → 90, 34 → 98로 이동)이 있다. 하드웨어 카운터 없이는 구분할 수 없다. 명세대로 1시간 안의 확인 가능 범위만 적는다.
