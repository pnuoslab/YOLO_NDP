### 1-2. Baseline에도 `-cv_threads` (참고 측정용)

diff는 `src/detector.c` 한 줄이다.

```diff
-    if (use_ndp && cv_threads >= 0)
+    if (cv_threads >= 0)
         cv_threads_eff = ndp_set_cv_threads(cv_threads);
```

`ndp_set_cv_threads()`는 `cv::setNumThreads(n)` 호출 하나다. 기본값은 −1(호출 안 함)이고, 표준 Baseline 실행은 이 옵션을 주지 않는다(블록 A·C·E·G의 명령줄로 확인, §3).

같은 커밋에서 바꾼 것이 하나 더 있다. `/proc/self/stat` CPU 교차 검증을 루프 앞에서 읽지 않고, 루프 뒤에 **프로세스 전체 CPU를 두 방식으로 나란히** 읽도록 옮겼다(`host_cpu_procstat_s` / `host_cpu_rusage_total_s`). 521회 전부 차이 ≤ 0.02 s다.
