**정리**
- 전송량(페이로드, NIC, 메타 읽기)은 **MB = 10⁶ B**다.
- 메모리(host VmHWM, storage 세 항)는 **MiB = 2²⁰ B**다.
- 같은 1080p 원본이 전송량 표에서는 152.6(MB), storage 읽기 버퍼에서는 145.5(MiB)로 찍힌다. 같은 raw 결과도 1,867.5(MB)와 1,781.0(MiB)로 찍힌다.
- 논문에서 하나로 통일하려면 메모리 ×1.048576(→ MB) 또는 전송량 ÷1.048576(→ MiB) 중 하나를 고르면 된다.
